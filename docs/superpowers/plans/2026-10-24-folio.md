# Folio Implementation Plan

> Execute inline using superpowers:executing-plans. Run final checks with the required test_runner subagent.

**Goal:** A desktop PDF reader with four contextual AI actions.
**Architecture:** Tauri wraps a vanilla Vite/PDF.js frontend; a Rust command calls an OpenAI-compatible Chat Completions endpoint.
**Tech stack:** Rust, Tauri 2, reqwest, serde, PDF.js, JavaScript, CSS.
**Spec:** `docs/superpowers/specs/2026-10-24-folio-design.md`.

## Global constraints

- Separate `folio` folder; existing projects stay untouched. This parent is not a usable Git repository, so no worktree or commits apply.
- macOS-inspired outline icons; no Material You.
- Memory-only settings; explicit AI sends; no redirects; HTTPS except loopback.
- One visible page; snapshot source and labels; no OCR.
